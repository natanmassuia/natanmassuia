### Sobre Mim

AI Engineer construindo produtos com orquestracao de LLMs, agentes autonomos e MCP na **Verbum Lab**. Meu foco esta em arquitetar sistemas de IA que funcionam em producao — com memory management, context windows, tool use e handoff humano-IA.

Trago base solida em operacoes criticas e infraestrutura (98% de SLA, ITIL V3), o que me da visao de estabilidade e monitoramento em sistemas de producao.

* **O que estou construindo:**
  * **Kore** — CRM + WhatsApp + AI Agent. Agente autonomo que gerencia conversas, qualifica leads e agenda compromissos usando orquestracao de LLMs (Claude API + OpenAI) com memory management e skills configuraveis.
  * **Looply** — Automacao operacional com orquestracao multi-modelo de LLMs. Converte dialogos em acoes estruturadas via WhatsApp, com pipeline de aprovacao, handoff humano-IA e MCP servers.

* **Stack principal:** Node.js, TypeScript, PostgreSQL, Prisma, Redis/BullMQ, Docker, NGINX, Claude API, OpenAI API, MCP Protocol
